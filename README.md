# Fraction Chess — v0.3 (поле боя с 3D-моделями)

Шахматы фракций: Люди, Орки, Нежить, Демоны, Эльфы, Гномы, Хтонь — у каждой свои фигуры и способности.

- **Играть в браузере:** GitHub Pages этого репозитория (собирается автоматически из `main`, `.github/workflows/pages.yml`).
- **Windows:** `FractionChess.zip` в разделе Releases — распаковать и запустить `FractionChess.exe`.
- **Движок:** чистый JavaScript + three.js (WebGL); модели — Meshy, облегчены в Blender скриптами из `tools/`.

**Запуск:** `dist\FractionChess.exe` — открывает игру с 3D-моделями (`index-gl.html`) в отдельном окне.
Лаунчер поднимает локальный сервер только на localhost: браузер не загружает 3D-модели с `file://`.
Для разработки — `serve.ps1` (http://localhost:8765/index-gl.html).

## Телефон (Android и iPhone) — веб-приложение (PWA)
`powershell -ExecutionPolicy Bypass -File build-web.ps1` собирает папку `web\` (~13,5 МБ): её содержимое выкладывается на любой
хостинг с https (GitHub Pages, Netlify, Cloudflare Pages). На телефоне: открыть ссылку →
Android/Chrome: меню ⋮ → «Добавить на главный экран» / «Установить»; iPhone/Safari: «Поделиться» → «На экран „Домой“».
После первого открытия игра работает без интернета (все файлы кэширует `sw.js`). Играется горизонтально:
манифест просит альбомную ориентацию, в вертикальном положении показывается «Поверните телефон».
Раскладка для телефона — `css/mobile.css`, полный экран и офлайн-кэш — `js/mobile.js`, иконки — `tools/make_icons.ps1`.

## Интерфейс поля боя (index-gl.html)
Поле на весь экран. Слева вверху — меню (справочник, правила, новая игра, ход назад/вперёд, журнал ходов, кнопка 👁 —
журнал прямо на экране, режим камеры). Сверху по центру — виды: изометрия, под углом, сверху. Справа вверху при выборе
фигуры загорается кнопка ⓘ — карточка фигуры с неоновой схемой ходов. Камера по умолчанию свободная (не крутится сама);
в меню можно включить поворот к игроку после каждого хода. Разметка — `css/hud.css`.

## Онлайн-игра
Кнопка «🌐 Онлайн-игра» на стартовом экране: один игрок создаёт комнату (играет Белыми) и отправляет другу ссылку
`…/fraction-chess/?room=КОД` или сам код, второй открывает ссылку (играет Чёрными). Каждый выбирает свою фракцию,
жребий бросает создатель комнаты. Устройства соединяются напрямую (WebRTC, библиотека PeerJS — `js/vendor/peerjs.min.js`);
для знакомства устройств используется бесплатный публичный сервер PeerJS. Передаются только ходы: правила детерминированы,
и второе устройство находит у себя то же действие (`js/ui.js`, раздел «сетевая партия»; соединение — `js/net.js`).
Ход назад в онлайн-игре недоступен; если соперник отключился, партию можно доиграть на своём устройстве.
Из exe ссылка-приглашение ведёт на сайт игры (GitHub Pages).

## Обучение с ботом
Кнопка «🎓 Обучение с ботом» на стартовом экране: вы играете Белыми (фракция Игрока 1), бот — Чёрными (фракция Игрока 2).
Ферзь бота или фигура, заменяющая ферзя (Вождь орды, Король демонов, Лич), в окне справа внизу объясняет каждый ход бота:
как ходит фигура, что произошло, какие комбинации использованы (вилка, двойное взятие, похищенный ход, «Строй», дальняя атака,
призыв, превращение) и зачем; даёт советы, когда ваша фигура под ударом, и коротко комментирует ваши ходы. Код — `js/tutor.js`.
Окно сворачивается нажатием на заголовок.

## Страницы
- `index-gl.html` — **основная**: WebGL-поле на three.js. Доска из двух половин — у каждой стороны доска её фракции
  (Демоны — адская доска `models/boards/demons.glb`, остальные — болото); фигура на чужой половине перекрашивает клетку под свою доску.
  3D-модели есть у Нежити и Демонов; у остальных фракций пока временные фигуры.
- `index3d.html` — упрощённый 3D-вид (CSS), работает и двойным кликом.
- `index.html` — классический 2D-вид.
- `tests.html` — автотест правил; `balance.html` — тест баланса; `analyze.html` — анализ причин дисбаланса.

## Код
`js/engine.js` — правила; `js/factions/*.js` — фигуры; `js/ui.js` — интерфейс; `js/ai.js` — ИИ;
`js/gl/board3d.js` — WebGL-поле; `js/vendor/` — three.js r170; `js/camera3d.js` + `css/style3d.css` — CSS-3D.

## 3D-модели
`models/undead/*.glb`, `models/boards/swamp.glb` — облегчённые копии моделей Meshy (≈30 тыс. треугольников, текстуры 1024).
Добавить модель:
```
blender -b модель.blend --python tools/convert_model.py -- models/<фракция>/<тип>.glb 30000 1024 piece
```
и указать её в `MODEL_FOR` в `js/gl/board3d.js` (тип фигуры → путь).

Диорама `models/boards/swamp.glb` собирается скриптом `tools/make_board8.py`: из болотной диорамы Meshy (поле 8×10)
вырезаются два средних ряда, клетки делаются квадратными, сверху кладётся модельная доска 8×8 (каменные плитки с фасками и швами):
```
blender -b swamp_chess_diorama.blend --python tools/make_board8.py -- models/boards/swamp.glb 150000 2048
```
Скрипт пишет разметку клеток в `<out>.json` (копия — `tools/board8_layout.json`); эти числа стоят в `BOARD` в `board3d.js`.
Вспомогательные скрипты: `tools/inspect_blend.py` (сводка по .blend), `tools/preview_blend.py` (рендер-превью), `tools/board_probe.py` (поиск игровой области диорамы).

Пересборка .exe: `powershell -ExecutionPolicy Bypass -File build.ps1`.
